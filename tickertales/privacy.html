Privacy Policy – Ticker Tales Uploader

Last updated: November 14, 2026

Ticker Tales Uploader ("the app") is a private tool operated by the owner of the Ticker Tales YouTube channel. It is not offered to the public.

What the app accesses

With the channel owner's permission, the app uses Google's YouTube Data API and YouTube Analytics API to upload the channel's own videos, set their titles, descriptions, thumbnails and captions, and read the channel's own performance statistics.

What the app does not do

  • It does not access any other user's account or data.
  • It does not sell, share or transfer any data to third parties.
  • It does not use data for advertising.

Storage

Authorization tokens are stored only on the channel owner's own computer. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
